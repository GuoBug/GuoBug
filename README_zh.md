### 👨‍💻 关于我 / About Me

专注于 **AI Workflow 编排、企业级系统产品化、软硬件极客工具与分布式基础设施**。

拥有 10+ 年操盘全球顶级开发者工具开源商业化与亿级消费级平台的产品工程经验。在当下的 AI 原生时代，我深度推崇 **人机协同共创（AI Pair Programming）** 与 **“干中学（Learning by Doing）”** 的工程闭环——立足真实业务痛点定义系统走向与关键里程碑，在人机双向启发中完成原理深挖、边界测试与代码落地。
